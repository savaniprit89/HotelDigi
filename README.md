# HotelDigi

HotelDigi is a **hotel management and booking web application** that allows users to browse hotel rooms, make reservations, and manage bookings through a modern web interface.

The system provides tools for both **customers** and **administrators** to manage hotel operations digitally.

---

## Tech Stack

**Frontend**
- React
- React Router
- Axios
- CSS / UI components

**Backend**
- Node.js
- Express
- MongoDB

---

## Features

### User
- Browse available hotel rooms
- View room details
- Book rooms online
- Manage reservations

### Admin
- Manage rooms
- Manage bookings
- Update room availability
- Monitor hotel operations
